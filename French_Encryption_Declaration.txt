# FRENCH ENCRYPTION DECLARATION
## Grid App - Compliance Documentation

**App Information:**
- App Name: Grid
- Bundle ID: com.bryandebourbon.grid
- Developer: Bryan de Bourbon
- App Type: Social Networking Application
- Version: 1.0

**Encryption Usage Declaration:**

This application uses encryption exclusively for the following purposes:

1. **Message Encryption**
   - Content algorithm: AES-256-GCM (Advanced Encryption Standard)
   - Key agreement: Curve25519 (X25519) via Apple CryptoKit
   - Content keys: random AES-256-GCM keys, wrapped to sender and recipient with ephemeral ECDH + HKDF-SHA256 + AES-GCM
   - Private key storage: iOS Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`)
   - Purpose: end-to-end encryption of private user messages and images

2. **Standard System Encryption**
   - CloudKit data encryption (managed by Apple)
   - HTTPS/TLS for network communications
   - iOS Keychain storage encryption

**Compliance Statement:**

The Grid application complies with French encryption regulations by:

- Using only internationally recognized, standard encryption algorithms
- Implementing no proprietary or military-grade encryption methods
- Utilizing Apple's publicly available CryptoKit framework
- Not implementing any encryption restricted for commercial software

**Technical Specifications:**

- Encryption Type: Symmetric (AES-256-GCM) and asymmetric key agreement (Curve25519)
- Key Management: CryptoKit + iOS Keychain
- Data Classification: Personal communications only
- Export Classification: Freely available cryptographic software

**Declaration:**

This application uses only standard, internationally accepted encryption algorithms that are freely available and not subject to French encryption restrictions for commercial software distribution.
